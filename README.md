## ⚡ Tech Stack & Architecture

* **Framework**: React 19 + Vite 8
* **Routing**: `react-router-dom` v7 with seamless scroll transitions and route protection
* **Icons**: `lucide-react`
* **Linter**: `oxlint` (0 warnings, 0 errors)
* **Design System**: Luxury Obsidian Dark mode with electric crimson accents (`#ff1e27`), Google Fonts `Barlow Condensed` & `Plus Jakarta Sans`
* **Animations**: Progressive Web Animations scroll-reveal hook (`useScrollReveal.js`) with zero third-party bloat

## 🚀 Quick Start

### 1. Install dependencies
```bash
npm install
```

### 2. Start local development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for production
```bash
npm run build
```

### 4. Run linter
```bash
npm run lint
```
